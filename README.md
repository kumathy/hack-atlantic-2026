# Thorpe Watch
A web app that tracks truck incidents involving the Bill Thorpe Walking Bridge and provides a public timeline of past incidents.

## About
On days without an incident, the homepage shows how many days have passed since the last incident, including the date of the last reported incident.
On the day that an incident occurs, the homepage reports a road closure notice. The road closure map is there to indicate where the incident is and which roads
are closed.
Users can submit reports to notify us that an incident has occurred and subscribe to future incident alerts via email.
